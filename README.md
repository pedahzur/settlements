# Settlements: Quantitative Panel and Interactive Map

A reproducible settlement-level research dataset combining population,
electoral, socio-economic, built-up-area, and geographic measures for Israeli
settlements and related localities in the West Bank, East Jerusalem, and the
Golan Heights.

**[Explore the interactive map](https://pedahzur.github.io/settlements/)**

**Repository:** [github.com/pedahzur/settlements](https://github.com/pedahzur/settlements)

> **Release status:** Version 0.1.0 is a public research release under active
> development. Entity matching, operationalizations, and derived measures may
> change as source coverage and validation improve.

The repository contains two connected products:

1. `settlements_master_panel.xlsx`, the curated research workbook containing
   the long population panel, entity registry, outpost inventory, source audit,
   crosswalks, and trajectory summaries; and
2. `db/`, a reproducible settlement-keyed database generated by `pipeline/`
   that adds election, socio-economic, and built-up-area measures.

## Headline coverage

Counts describe the committed outputs from the **6 July 2026** refresh.

| Component | Coverage |
|---|---:|
| Canonical entity registry | 522 entities |
| Entities with coordinates | 503 |
| Population panel | 7,661 entity-years, 1969–2024 |
| Voting panel | 9,611 locality-elections, Knesset 18–25 |
| Socio-economic table | 255 matched localities |
| Built-up-area table | 133 matched settlements |
| Master research panel | 9,396 entity-years |

The registry contains 148 West Bank settlements, 315 outposts, 11 East
Jerusalem entities, nine Hebron or B'Tselem-only entities, 34 Jewish Golan
localities, and five Druze/Alawite Golan localities included for comparison.
These are mixed legal and analytical categories; **522 is not an official
settlement count**.

## Headline findings

Current descriptive results are documented in
[`settlements_empirical_brief.md`](settlements_empirical_brief.md):

- The population of West Bank settlements excluding East Jerusalem rose from
  approximately 139,000 in 1996 to 497,000 in 2024, about a 3.6-fold increase.
- Growth is uneven across settlement forms and regions. Urban and community
  settlements grew faster than agricultural settlements, while the Jordan
  Valley contains much of the stagnant or declining tail.
- Across 128 West Bank settlements, growth correlates negatively with distance
  from the Green Line (`r ≈ -0.35`). This is descriptive association, not a
  causal estimate.
- Peace Now identifies 315 outposts. The source files do not provide an official
  population series for them.
- In the Golan comparison, the Jewish population increased from 16,510 in 2003
  to 29,950 in 2024; the five Druze/Alawite comparison localities contained
  27,661 residents in 2024.
- In 2,614 overlapping Peace Now/B'Tselem settlement-years, 89.7% of population
  observations match exactly and 95.3% differ by no more than 1%.

These findings depend on the source definitions and operational choices stated
below and should be read with the continuous measures in the workbook.

## Method and pipeline

`python -m pipeline.run_all` performs two stages:

1. `pipeline.consolidate` builds the canonical entity dimension and population,
   voting, socio-economic, expansion, and latest-snapshot tables, then writes
   CSV and SQLite outputs.
2. `pipeline.build_geojson` converts the snapshot and population panel into the
   files consumed by the static map.

Every generated fact table joins to `settlement_dimension.csv` through
`settlement_id`. Israeli administrative sources first attach through CBS
locality code (`cbs_semel`) and then fall back to a normalized Hebrew-name key.
Unmatched records remain visible rather than being forced to an entity.

The weekly GitHub Actions workflow runs the pipeline each Monday, commits
changed `db/` and `web/data/` outputs, and deploys `web/` to GitHub Pages.
Network downloads are cached under ignored `db/raw/`; a fresh offline run may
omit network-derived tables when neither a host nor a cache is available.

## Setup and reproduction

The project targets Python 3.12 or newer. With
[`uv`](https://docs.astral.sh/uv/) installed:

```bash
uv venv
uv pip install -r requirements.txt
uv pip install "geopandas>=0.14" "shapely>=2.0" pyogrio
uv run python -m pipeline.run_all
```

Preview the generated map at <http://localhost:8000>:

```bash
uv run python -m http.server --directory web 8000
```

Rebuild the standalone Golan summary from the committed CBS extracts:

```bash
uv run python analysis/build_golan.py --output analysis/golan_data.json
```

The Golan registry contains 34 Jewish localities, but the annual series contains
33 because CBS does not publish a population for Nimrod.

## Sources, provenance, and caveats

The integrated sources are Peace Now Settlement Watch, B'Tselem, Israel Central
Bureau of Statistics, the Israel Central Elections Committee/data.gov.il, and
UN OCHA oPt/HDX. See [`SOURCES.md`](SOURCES.md) for exact endpoints, formats,
coverage, ingestion status, and reliability notes.

Key limitations:

- Entity definitions differ across sources and should not be treated as legally
  equivalent categories.
- East Jerusalem entity-level coverage is primarily B'Tselem-derived and ends
  in 2017.
- Golan annual locality coverage begins in 2003; Nimrod has no published series.
- `expansion.csv` is a cross-sectional built-up-area snapshot, not a historical
  expansion series.
- Party-bloc membership and trajectory thresholds are research
  operationalizations, not official classifications.
- The latest population year is 2024; a 2026 refresh does not imply that every
  source has released 2026 observations.
- Third-party source files and observations remain subject to their providers'
  terms. See [`THIRD_PARTY_NOTICES.md`](THIRD_PARTY_NOTICES.md).

## AI-assisted workflow

Claude and Codex were used interactively to assist with source organization,
pipeline development, crosswalk construction, data-quality checks, analysis,
and documentation. The prompt strategy was task-specific: identify source
schemas and join keys, propose transformations, run reproducible checks against
committed artifacts, and revise outputs when checks exposed inconsistencies.

**Human validation:** Ami Pedahzur reviewed source selection, entity matching,
operational definitions, descriptive claims, figures, and published outputs.
AI-generated suggestions were not treated as evidence without comparison to the
underlying files or named sources.

**Not yet validated:** the complete crosswalk has not received independent
external audit; the trajectory classification has not been replicated by a
second analyst; and the integrated database and descriptive findings have not
yet undergone formal independent replication.
