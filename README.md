# Settlements: Quantitative Panel and Interactive Map

> **Work in progress.** This private research repository is under active
> development. Definitions, crosswalks, and derived measures may change as the
> underlying sources and manuscript develop.

**[Explore the public interactive map](https://pedahzur.github.io/settlements/)**

This project assembles a settlement-level panel for the quantitative study of
Israeli settlements and related localities in the West Bank, East Jerusalem,
and the Golan Heights. It brings population, electoral, socio-economic,
built-up-area, and geographic measures into a common entity registry and
publishes both analysis-ready files and a static interactive map.

The repository contains two related data products:

1. `settlements_master_panel.xlsx`, the curated research workbook used for the
   empirical analysis and manuscript; and
2. `db/`, a reproducible settlement-keyed database generated by `pipeline/`.

They overlap, but they are not interchangeable. The workbook contains the
long-run research panel, source agreement audit, crosswalks, outpost inventory,
and trajectory summaries. The pipeline adds remotely fetched election,
socio-economic, and built-up-area measures to a canonical registry.

## Current coverage

Counts below describe the committed outputs from the **6 July 2026** refresh.

| Component | Current coverage |
|---|---:|
| Canonical entity registry | 522 entities |
| Entities with coordinates | 503 |
| Population panel | 7,661 entity-years, 1969–2024 |
| Voting panel | 9,611 locality-elections, Knesset 18–25 |
| Socio-economic table | 255 matched localities |
| Built-up-area table | 133 matched settlements |
| Master research panel | 9,396 entity-years |

The 522 registry entities comprise 148 West Bank settlements, 315 outposts, 11
East Jerusalem entities, nine Hebron or B'Tselem-only entities, 34 Jewish Golan
localities, and five Druze/Alawite Golan localities included for comparison.
Because the registry mixes different legal and analytical categories, its total
should not be read as a single official settlement count.

## Quick start

The project targets Python 3.12 or newer and uses a small pandas-based pipeline.
With [`uv`](https://docs.astral.sh/uv/) installed:

```bash
uv venv
uv pip install -r requirements.txt
uv run python -m pipeline.run_all
```

The built-up-area step additionally requires the optional geospatial stack:

```bash
uv pip install "geopandas>=0.14" "shapely>=2.0" pyogrio
```

Preview the generated map at <http://localhost:8000>:

```bash
uv run python -m http.server --directory web 8000
```

The pipeline caches network downloads under ignored `db/raw/`. When a remote
source is unavailable, the corresponding step uses a local cache or degrades to
an empty table. A fresh offline run therefore reproduces the local population
and geography but may not reproduce every network-derived table unless its
cache is already present.

## How the pipeline fits together

`python -m pipeline.run_all` performs two stages:

1. `pipeline.consolidate` builds the entity dimension, population, voting,
   socio-economic, and expansion tables; writes CSV and SQLite outputs; and
   produces the latest wide snapshot.
2. `pipeline.build_geojson` converts the snapshot and population series into
   `web/data/settlements.geojson`, `population_by_year.json`, and `meta.json`.

Every generated fact table joins to `settlement_dimension.csv` through
`settlement_id`. Remote Israeli sources first attach through CBS locality code
(`cbs_semel`) and then fall back to a normalized Hebrew-name key.

The master workbook remains the source for the canonical research registry,
population history, and trajectory measures. The generated database is the
integration layer for additional variables and the interactive map.

## Automated refresh

`.github/workflows/weekly-update.yml` runs each Monday and can also be started
manually. The workflow:

1. installs the core and optional geospatial dependencies;
2. runs the complete pipeline;
3. commits changed `db/` and `web/data/` outputs; and
4. deploys `web/` to GitHub Pages.

The most recent scheduled run completed successfully. Generated timestamps and
network-derived row counts can change even when the pipeline code does not.

## Research artifacts

The master workbook includes:

- `master_panel_long`: 9,396 entity-year observations;
- `settlement_summary`: West Bank growth and trajectory measures;
- `golan_summary`: 39 Golan registry entities over the 2003–2024 analysis
  window;
- `entity_registry`: the 522-entity canonical registry;
- `outposts`: 315 Peace Now outpost records;
- `source_agreement`: 2,614 overlapping Peace Now/B'Tselem settlement-years;
- `crosswalk`: matched source identifiers; and
- `peacenow_settlements_wide`: the original wide Peace Now series.

`analysis/build_golan.py` reconstructs the standalone Golan summary from the two
committed CBS CSV files:

```bash
uv run python analysis/build_golan.py --output analysis/golan_data.json
```

The Golan registry contains 34 Jewish localities, but the annual series contains
33 because CBS does not publish a population for Nimrod.

## Sources and provenance

The project currently integrates:

- **Peace Now Settlement Watch** for the long West Bank population series,
  settlement attributes, and outpost inventory;
- **B'Tselem** for complementary population observations, especially East
  Jerusalem and Hebron entities absent from Peace Now;
- **Israel Central Bureau of Statistics** for Golan population and registry
  data and socio-economic measures;
- **Israel Central Elections Committee / data.gov.il** for locality-level
  election results; and
- **UN OCHA oPt / HDX** for the latest built-up-area polygons.

See [SOURCES.md](SOURCES.md) for exact endpoints, formats, coverage, reliability
notes, and sources considered but not currently ingested.

## Methodological limitations

- **Entity definitions differ across sources.** The canonical registry preserves
  source categories rather than treating every row as legally or analytically
  equivalent.
- **East Jerusalem coverage is incomplete.** The current entity-level series is
  primarily B'Tselem-derived and ends in 2017.
- **Golan coverage begins in 2003.** Earlier locality-level annual CBS files are
  unavailable, and Nimrod has no published population series.
- **Built-up area is cross-sectional.** `expansion.csv` records the latest
  matched OCHA polygon area, not historical physical expansion.
- **Source matching is best effort.** CBS codes are preferred; normalized Hebrew
  names are used where codes are missing. Unmatched observations remain visible
  rather than being silently forced to an entity.
- **Derived political measures are operationalizations.** Party-bloc membership
  and trajectory thresholds are editable research choices, not official
  classifications.
- **The latest population year is 2024.** A 2026 repository refresh does not
  imply that every source has released 2026 observations.

## Status and reuse

This is an active research repository, not a finished public data release. The
data model, crosswalks, derived measures, analysis, and manuscript are still
being revised. No repository-wide reuse license or formal citation file has yet
been declared; contact the author before redistributing the compiled data.

Corrections to source matching, provenance, or methodology are welcome through
GitHub issues or pull requests from collaborators with repository access.
